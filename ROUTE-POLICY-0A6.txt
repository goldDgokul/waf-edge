POLICY DEFINITIONS
------------------
Public   No token required. Contains only service discovery, liveness, monitoring or login.
Viewer   Any authenticated viewer/operator/admin. Read-only operational data.
Operator Authenticated operator/admin. Starts, stops, configures, generates or deploys operational state.
Admin    Authenticated admin only. User, security and cluster membership administration.
Closed   Must not be registered or served in the production application.

The served panel makes protected API calls before any login flow exists.

0A.6 ACCEPTANCE BOUNDARY
------------------------
1. Public routes remain reachable without a token.
2. Missing/invalid credentials on Viewer, Operator and Admin routes return 401.
3. Authenticated users below the route's role return 403.
4. Excessive login attempts return 429.
5. Closed routes are not registered/served.
6. /api/health returns a truthful non-500 response under expected degraded conditions.
7. Credential-bearing wildcard CORS is removed from both FastAPI and the control-panel proxy.
8. The panel cannot request protected data before login and sends the bearer token after login.
9. This minimal login is a Phase 0A control-plane guard, not the final multi-tenant identity system.
10. ML remediation remains deferred; adding authorization to /api/training/start does not authorize starting ML remediation work.
